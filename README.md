# Notes From a Passive-Aggressive Fridge

A single passive-aggressive note a smart fridge leaves for its owner:

> You opened me 14 times today and ate nothing. The leftover lasagna watched you do it. We are both disappointed.

The joke is the fridge keeping score: it counted every door opening, noticed nothing was ever taken, and drafted the one thing in the house that has been silently witnessing it all — the leftover lasagna — as a co-signer of the complaint. The fridge is not angry, just quietly keeping receipts, and the sting lands when the appliance and the leftovers form a united front of disappointment.

## Run it

```sh
node main.ts
```

This writes the note to `/output/entry.txt` (no trailing newline). The program is deterministic: every run produces byte-identical output.
